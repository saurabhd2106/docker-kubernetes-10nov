What we write about

The Build Log is written by engineers who build and run production systems. We publish long-form articles about modern Java, running services on containers and cloud platforms, deployment pipelines and operations, and the architecture decisions that tie them together. Every article comes from something we actually built, broke, or fixed.

Articles are grouped into four topics: Java, Cloud, DevOps, and Architecture. You can also browse the full archive or search every article.

How this site is built

This blog doubles as the sample application for the Docker and Kubernetes training. It is a plain Java program with no framework and no database:

  • Articles are HTML files with a short metadata header, bundled inside a single JAR.
  • At startup, the server renders every page into memory, so each request is a simple lookup.
  • The JDK's built-in HTTP server answers requests on virtual threads.
  • Search runs in your browser against a small JSON index; nothing is sent to a server.

Things to try in the training

  • The footer of every page shows the container hostname, port, and Java version. Start two containers and compare.
  • /health returns ok and drives the image HEALTHCHECK.
  • The PORT environment variable changes the port the server listens on inside the container.
  • docker logs shows one line per request, plus a startup line with the number of rendered pages.
