About

Notes from the field, not the brochure

Container Field Notes is a small engineering blog about building .NET applications that run well in containers, and keep running well once they reach Kubernetes.

Most of what we write starts as a question someone asked in a code review or an incident channel. Why is this image 900 MB? Why does the port mapping do nothing? Why did every pod restart at once? We write the answer down properly, with commands you can run and output you can compare against.

Who writes here

Priya runs the internal Kubernetes platform that a few hundred services deploy to. She cares about boring, repeatable deployments and writes the "how it fits together" posts.

Marco Silva

Aisha Khan

Aisha is on call for the things the other two build. She writes about health checks, probes and the failure modes you only learn about at 3 a.m.

This blog is the demo

The site you are reading is a minimal ASP.NET Core app on .NET 10. There is no database and no CMS: Kestrel serves these HTML files out of the wwwroot folder baked into the image. It is the sample application for our Docker and Kubernetes training, so it is deliberately simple. That way the session can focus on the container: how the image is built, how the process starts, which port it listens on, and how Docker knows it is healthy.
